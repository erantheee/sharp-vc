# 决策审计单

决策审计单评估提案的证据与成熟度，不预测最终成功。保持简短、可执行，不生成修订稿。

## 输出格式

```
# Sharp VC 决策审计单

## 当前判断
[目前最诚实的判断，以及已经通过的最高闸门。直接陈述，不写“先说结论”或“一句话结论”。]

## 已验证的市场机会
- 问题市场已经成立的部分：
- 品类中已有的真实付款、持续使用、收入、企业采购或并购：
- 这些证据尚不能证明的具体产品形态：

## 为什么目前还不 OK
- 阻断放行的核心断点：
- 它可能造成的商业后果：
- 什么证据会改变判断：

## 最简因果链
[用户与情境] → [问题及当前替代] → [必要机制] → [行为或付费改变] → [可持续交付与回报]

## 论证账本
- 已成立：主张 + 证据标签
- 未证假设：主张 + 当前证据标签
- 矛盾：相冲突的两项内容
- 未知或暂缓：缺失内容及其影响

## Top 3 致命假设
1. 主张：
   - 失败条件：
   - 当前证据：
   - 为什么承重：
2. ...

## 替代与购买理由
- 用户今天怎么解决：
- 为什么现有替代仍被选择：
- 选择本产品而非别人的证据：

## 奥卡姆删减结果
- 已删除或应暂缓：
- 必须保留的唯一价值动作：

## 下一项最小验证
- 要验证的假设：
- 最小动作：
- 通过阈值：
- 停止或转向条件：

## 阶段闸门
- 已通过的最高层级：
- 尚未通过的下一层级：
- 阻断证据：
```

## 阶段闸门

闸门按顺序累积。不得跨过前一层直接宣布后层通过。

### 概念可立案

目标用户、具体情境、问题后果、当前替代和最小价值机制已经说清，核心命题可被证伪。只表示值得继续探索。

### 原型可立项

最关键的价值与技术假设有可执行的验证方案、阈值和停止条件，原型范围已经经过删减，成本与权限边界初步可控。

### 产品可立项

目标用户、竞品替代、关键体验、工程约束、成本和验收指标基本闭合，主要风险有责任人与验证路径。只靠演示或问卷不能通过。

### 商业可放行

存在足够的真实行为与付费证据，渠道、价格、毛利、交付、售后和增长条件可接受。市场规模或竞品成功不能替代本项目证据。

如果尚未通过任何闸门，写 `尚未达到概念可立案`，不要选择最接近的一层安慰用户。

## 文档定位

审视 PRD 或提案文档时，每个缺口应标出页码、章节或可识别段落，并说明：

- 当前文字实际声称了什么；
- 缺少哪段逻辑或证据；
- 作者需要回答什么；
- 哪种证据可以使其过关。

不要代写替换段落。确定性事实错误可以给出纠正依据，但采纳与修改仍由作者控制。
